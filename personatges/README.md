# Personatges

Fitxes i làmines de referència dels animals d'origami del joc.

- `aprovades/`: només làmines confirmades per l'autor.
- `pendents/`: proves o propostes encara no aprovades.

Respectar la silueta, els plecs de paper, els colors, els ulls i les proporcions de cada animal. No substituir les làmines aprovades.
